# 5. Multi-Plan Telecommunications Cost Optimization – Python Program

### 1. Problem Statement

Develop a Multi-Plan Telecommunications Cost Optimization System using Python. The program should evaluate different mobile recharge plans based on data usage, call minutes, SMS usage, validity period, and budget constraints. It should calculate additional charges for excess usage, identify eligible plans, and recommend the most economical plan.

### 2. Algorithm

1. Start the program.
2. Enter the customer's budget.
3. Enter the required validity period.
4. Enter expected data usage, call minutes, and SMS usage.
5. Define multiple mobile recharge plans with different prices and limits.
6. Check whether each plan satisfies the validity and budget conditions.
7. Calculate excess data, call, and SMS charges.
8. Calculate the total cost of each eligible plan.
9. Compare the total costs of all eligible plans.
10. Select the plan with the lowest total cost.
11. Display all plan details and recommend the most economical plan.
12. Stop the program.
